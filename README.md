# Personal AI Knowledge Vault landing page

This is the standalone public landing page for the iOS and Android app in private development. It contains the page, stylesheet, and original favicon. The site uses no JavaScript, forms, analytics, or external assets.

## Preview

Run `python3 -m http.server 8080` from this folder, then open [the local preview](http://127.0.0.1:8080/).

## GitHub Pages

Publish this folder in its own public repository, `personal-ai-knowledge-vault-site`. In **Settings → Pages**, select **Deploy from a branch**, then **main** and **/ (root)**. The empty `.nojekyll` file enables static publishing. Verify the URL shown by GitHub Pages in a signed-out browser. [GitHub Pages publishing settings](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
